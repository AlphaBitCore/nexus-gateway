# Provider adapter specs — binding rules

- **Adapter format-translation follows `provider-adapter-architecture.md` §3a (binding).** Any change under `packages/ai-gateway/internal/providers/specs/<name>/` (codec, stream session, error normalizer, hub_ingress) must conform to §3a Rules 1-12 before shipping: canonical = OpenAI shape; non-OpenAI adapters own their full canonical↔wire translation; per-model wire quirks stay in the adapter that talks to that wire (never in `spec_adapter.go`); extension fields ride inside `nexus.ext.<provider>.<key>` via `canonicalext`; cross-format callers canonicalize via `canonicalbridge.IngressChatToCanonical` before the codec; streaming + non-streaming parity; every prefix-list rule needs a comment citing the observed 400; a codec and its transport address the same wire shapes; a decoded response never reports success the upstream did not; an upstream error is annotated, never replaced; a field we coerced is a field we own. Run `/adapter-conformance-check` before completion.
